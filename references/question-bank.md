# 分系统问题库 + 患者自填表

> 配套 `SKILL.md` 使用。原则：**每轮≤3项，按优先级取，不要照着念全表。**

## 一、按系统的追问库

### 1. 寒热与汗（P0 · 最优先）

| 问什么 | 话术 | 异常指向 |
|---|---|---|
| 寒热偏向 | 「同样温度下，你比旁人更怕冷、差不多、还是更怕热？」 | 但寒不热=里寒；但热不寒=里热 |
| 寒热部位 | 「冷/热是全身还是某一处？手脚到哪一节？」 | **冷过肘膝=阳衰**；独膝冷=着 |
| 时间规律 | 「什么时候发热？下午？夜里？」 | 午后潮热=阳明/阴虚；夜热=阴分 |
| 出汗有无 | 「出汗吗？白天不动也出吗？」 | 自汗=阳虚/卫弱；无汗=表实 |
| 出汗时间 | 「睡着出汗还是醒着出汗？」 | 盗汗=阴虚/湿郁 |
| 汗的部位 | 「全身出还是只有头/手？汗黏不黏？」 | 头汗=湿热/虚阳上浮 |

### 2. 睡眠（P1）

| 问什么 | 话术 | 异常指向 |
|---|---|---|
| 入睡 | 「躺下多久能睡着？」 | 难入睡=心肾不交/肝郁 |
| 夜醒 | 「半夜会醒吗？几点醒？醒后能再睡吗？」 | **1–3点醒=肝经当令，肝已受损** |
| 早醒 | 「是不是天没亮就醒，再也睡不着？」 | 早醒=阳虚/血虚 |
| 梦与烦躁 | 「做梦多吗？心里烦不烦？」 | 多梦=心火；烦=虚热 |
| 晨起状态 | 「早上起来是轻松还是像没睡？」 | 不解乏=湿困/阳虚 |

### 3. 饮食与口味（P1）

| 问什么 | 话术 | 异常指向 |
|---|---|---|
| 胃口 | 「三餐有饱饿感吗？想吃吗？」 | **有胃气则生**；无食欲=脾胃败 |
| 食量 | 「比平时吃得少还是多？」 | 多食易饥=胃热/消渴 |
| 饭后 | 「吃完胀不胀？胀在哪？」 | 饭后胀=脾虚气滞 |
| 口味 | 「嘴里苦、甜、淡、黏、没味？」 | 苦=胆热；甜=脾湿；淡=脾虚 |
| 口渴 | 「口渴吗？想喝热的凉的？喝多少能解？」 | 喜冷=热；喜热/不渴=寒；**冷热皆可且不解=饮渴** |
| 饮水 | 「一天喝多少水？爱喝冰的吗？」 | 喜冰=里热；不喜饮=湿/寒 |

### 4. 大便（P1 · 太阴提纲主症）

| 问什么 | 话术 | 异常指向 |
|---|---|---|
| 频次 | 「一天几次？几天一次？」 | 便秘/自利 |
| 形态 | 「成形、溏软、水样、还是干硬成球？」 | **成形=脾胃尚运**；溏=湿 |
| 颜色 | 「深褐、淡黄、发黑、带血？」 | 黑=瘀/远血；淡=虚寒 |
| 排便感 | 「痛快吗？有没有排不干净？」 | 里急后重=湿热 |
| 气味 | 「臭不臭？酸腐味？」 | 酸腐=食积 |

> ⚠️ **「自利益甚」是太阴病提纲必备主症**——大便成形，则不可轻断太阴病。

### 5. 小便（P1 · 本案定方关键）

| 问什么 | 话术 | 异常指向 |
|---|---|---|
| 频次 | 「白天几次？夜里起夜吗？」 | 夜尿多=肾气不固 |
| 量 | 「一次量多还是少？」 | **量少=气化不行** |
| 颜色 | 「清长、淡黄、深黄、浑浊？」 | 清长=寒；短赤=热 |
| 通畅度 | 「解着顺吗？**有没有解不干净、还有残余的感觉？**」 | **= 《伤寒论》「苦里急」，五苓散主证** |
| 疼痛 | 「尿道热、痛、涩？」 | 淋证 |

### 6. 头面与五官

| 问什么 | 话术 | 异常指向 |
|---|---|---|
| 头晕 | 「晕是天旋地转还是昏沉？」 | 旋转=痰饮/肝风；昏沉=湿困 |
| 头痛 | 「痛在哪？胀痛、跳痛、空痛？」 | 部位定经 |
| 眼睛 | 「干、涩、胀、红、模糊、畏光？」 | **眼干先辨：阴虚 vs 湿阻清阳不升** |
| 耳鸣 | 「蝉鸣还是轰响？按下去舒服吗？」 | 高音=虚；低音/按之舒服=虚 |
| 口咽 | 「口干？咽干？有痰？」 | 但欲漱水不欲咽=瘀 |

### 7. 四肢与躯体

| 问什么 | 话术 | 异常指向 |
|---|---|---|
| 手足温度 | 「手温还是凉？脚呢？**冷到哪一节**？」 | 肘膝以上=阳衰重证 |
| 膝 | 「膝盖单独冷吗？和脚比？」 | **独膝冷=寒湿着于下焦（非肾阳虚）** |
| 沉重感 | 「腿沉不沉？像灌铅？」 | 沉=湿；「当汗出而不汗出」=溢饮 |
| 酸麻 | 「酸、麻、木、抽筋？什么时候明显？」 | 血不养筋 |
| 水肿 | 「按下去有没有坑？早上眼皮肿吗？」 | 晨起头面浮肿=水气 |
| 腰背 | 「腰酸吗？酸在哪？弯腰舒服还是更痛？」 | 腰为肾之府 |

### 8. 精神体力

| 问什么 | 话术 | 异常指向 |
|---|---|---|
| 精力 | 「白天有劲吗？到几点就没劲？」 | 但欲寐=少阴 |
| 情绪 | 「容易烦、急、郁闷、想哭？」 | 脏躁/肝郁 |
| 记忆 | 「记性差了吗？注意力散？」 | 肾精/心血 |

### 9. 男科（男性必问，敏感但不可省）

| 问什么 | 话术 | 异常指向 |
|---|---|---|
| 晨勃 | 「早上有反应吗？」 | 肾阳直接指标 |
| 性功能 | 「欲望和硬度有变化吗？」 | 肾阳/肝血 |
| 夜尿 | 「夜里起几次？」 | 肾气不固 |
| 会阴 | 「会阴坠胀、排尿末滴白？」 | 前列腺相关 |
| **⚠️ 泌尿科提示** | 尿量少 + 排尿不净 + 残余感 = 与前列腺增生表现重叠 | **须先查尿常规/残余尿/PSA/超声，排除器质性梗阻** |

### 10. 女性（必问）

| 问什么 | 话术 | 异常指向 |
|---|---|---|
| 周期 | 「多久一次？准不准？」 | 提前=热；延后=寒 |
| 量色 | 「量多还是少？色淡还是黑？有血块？」 | **色淡=小肠热不足；色黑=烤焦** |
| 伴随 | 「痛经？乳胀？腰酸？」 | 肝郁/寒凝 |
| 带下 | 「量、色、味？」 | 黄稠=湿热；清稀=寒湿 |

### 11. 旧病与用药（必问，防误治）

- 「以前得过什么病？做过手术吗？」
- 「现在长期吃什么药？中药西药都算。」
- 「吃过什么中药？有效吗？吃完有什么反应？」
- **「最近在喝什么茶、吃什么保健品？」**——很多人把寒凉代茶饮当养生，方向反了自己不知道
